# 🧮 Voice Calculator

A smart calculator built with HTML, CSS, and JavaScript — with **voice input support**!

---

## ✨ Features

- ➕ Basic operations — Add, Subtract, Multiply, Divide
- 🎙️ Voice assistance — speak your calculation, get the answer
- 🔢 Decimal number support
- ⌫ Backspace & Clear (AC) buttons
- 📱 Responsive design
- ⚡ Instant calculation with JavaScript

---

## 🛠️ Tech Stack

**HTML** — Structure  
**CSS** — Styling & layout  
**JavaScript** — Logic, calculations & Web Speech API

---

## 🎙️ How Voice Works

Uses the browser's built-in **Web Speech API** — no external library needed!

- Click the 🎙️ mic button
- Say something like *"five plus three"*
- Calculator computes and shows the result

> ⚠️ Works best on Chrome browser

---

## 🚀 How to Run

```bash
# Clone
git clone https://github.com/your-username/voice-calculator.git

# Just open index.html in Chrome — no setup needed!
```
